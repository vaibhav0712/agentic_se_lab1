# SG-11: Day mode palette (version 2)

Status: ACTIVE (version 2)
Category: Color

The day mode uses a warm, paper-like look.

- Page background MUST be `#FFF8E7` (warm off-white).
- Main text color MUST be `#1D1D1F`.
- Secondary text SHOULD be `#5A5A5F`.
- Card background SHOULD be `#FFFFFF` with a subtle shadow.

Define the colors as CSS custom properties for the light theme, for example `--bg` and `--text`,
and use the variables everywhere instead of repeating the hex values.
