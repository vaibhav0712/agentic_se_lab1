# SG-24: Header

Status: ACTIVE
Category: Components

The header is the first thing visitors see.

- It contains the group name as the only `h1` of the page, see the heading hierarchy document.
- Below the name: a one-sentence tagline, for example "Five humans, one agent, zero deployed bugs (so far)".
- The theme toggle sits in the top right corner.
- The header MAY use the gradient described in the gradients document.
