# SG-17: Gradients and shadows

Status: ACTIVE
Category: Color

- Gradients MAY be used in the header, going from the page background to a 10% tint of the accent.
- Cards SHOULD have a soft shadow in day mode (for example `0 2px 8px rgba(0,0,0,0.08)`).
- In night mode, replace shadows with a 1px border in a slightly lighter blue.
