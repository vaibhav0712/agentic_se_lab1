# SG-52: Typography scale

Status: ACTIVE
Category: Typography

All font sizes MUST be given in `rem`. Pixel font sizes are not allowed, because they ignore the user's browser settings.

| Element | Size |
|---|---|
| body | 1rem |
| h1 | 2.5rem |
| h2 | 1.75rem |
| h3 | 1.25rem |
| hot take badge | 0.9rem |
| footer | 0.8rem |

Line height of body text: 1.6.
