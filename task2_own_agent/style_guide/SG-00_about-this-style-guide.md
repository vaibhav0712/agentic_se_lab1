# SG-00: About this style guide

Status: ACTIVE (version 3)
Category: Meta

This style guide defines how team websites in the Agentic Software Engineering lab look and behave.
It is maintained by the (entirely fictional) UPB Web Design Board.

## How to read this guide
- Every document has an ID (SG-xx), a status and a category.
- Rules change over time. Old documents are kept for history and are marked as DEPRECATED in their header.
  A deprecated document names the document that replaces it.
- If two documents seem to contradict each other, the ACTIVE document wins.
- Words like MUST and MUST NOT are binding. SHOULD means strongly recommended. MAY means optional.

## Scope
The guide covers page structure, colors, theming, typography, responsive behaviour, content and tone.
It does not cover hosting, because team websites are delivered as a single local file.
