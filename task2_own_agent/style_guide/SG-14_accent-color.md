# SG-14: Accent color

Status: ACTIVE
Category: Color

Team websites use exactly one accent color: `#E4007C` (UPB magenta).

- The accent MUST be defined once as a CSS custom property named `--accent`, for example `:root { --accent: #E4007C; }`.
- The accent is the same in day and night mode.
- Use it only for: hot take badges, links, the focus outline and small highlights.
- Don't use the accent for large backgrounds or body text.
