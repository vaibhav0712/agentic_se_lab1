# SG-58: Review checklist

Status: ACTIVE
Category: Meta

Before submitting, go through this list:

- [ ] Title and language set as described in the metadata document
- [ ] Current day and night palettes used (not the deprecated ones)
- [ ] Accent color defined as a custom property
- [ ] Theme switching and persistence implemented as described in the theming documents
- [ ] Toggle is an accessible button
- [ ] One member card per member, each with a hot take badge
- [ ] Photos have alt texts
- [ ] Required sections with the correct ids
- [ ] Exactly one h1
- [ ] Current footer text
- [ ] Current breakpoint
- [ ] System font, rem font sizes
- [ ] Reduced motion respected
