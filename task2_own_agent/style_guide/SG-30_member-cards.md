# SG-30: Member cards

Status: ACTIVE (version 2)
Category: Components

Every team member is introduced in exactly one member card.

## Markup
- Each card MUST be an `<article>` element with the class `member-card`.
- There MUST be exactly one member card per team member. No placeholder cards.
- Cards are placed inside the team section, see the page structure document.
- Cards are ordered alphabetically by first name.

## Content of a card, in this order
1. Photo (see the member photos document)
2. Name as an `h3`
3. Study background in one line
4. Bio (see the bio writing document)
5. Hot take badge (see the hot take badge document)
