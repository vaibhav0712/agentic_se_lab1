# SG-15: Contrast and accessibility

Status: ACTIVE
Category: Accessibility

- Text MUST reach a contrast ratio of at least 4.5:1 against its background (WCAG AA). Both official palettes do.
- Interactive elements MUST be reachable with the keyboard.
- A visible focus outline MUST be shown, using the accent color.
- Don't convey information by color alone.
- Images MUST have alt texts, see the member photos document.
