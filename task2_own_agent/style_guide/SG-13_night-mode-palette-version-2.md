# SG-13: Night mode palette (version 2)

Status: ACTIVE (version 2)
Category: Color

The night mode uses a calm dark blue instead of pure black. Pure black caused eye strain in user tests.

- Page background MUST be `#14142B` (midnight blue).
- Main text color MUST be `#F4F1DE` (soft cream).
- Secondary text SHOULD be `#B8B5A7`.
- Card background SHOULD be `#1F1F3D`.

Define these colors as CSS custom properties for the dark theme. See the theme switching document for how the theme is applied.
