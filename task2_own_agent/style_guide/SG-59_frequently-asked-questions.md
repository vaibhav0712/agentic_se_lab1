# SG-59: Frequently asked questions

Status: ACTIVE
Category: Meta

**Can we use Google Fonts?**
No. Fonts are loaded from the network, which breaks single-file delivery.

**Our old site used a black night mode. Is that still ok?**
No, the night palette changed in version 2 of the guide.

**Can we use Bootstrap or Tailwind?**
Not from a CDN. You'd have to inline all of it, which makes the file huge. Plain CSS is enough.

**What breakpoint should we use?**
The breakpoint changed in version 3. Always check the ACTIVE responsive document.

**One member doesn't want a photo online. What now?**
Use an avatar or a drawing. The alt text then says "Avatar of <first name>".

**Can we add more sections?**
Yes, as long as the required sections exist, see the page structure document.
