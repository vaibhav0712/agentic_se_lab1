# SG-01: Glossary

Status: ACTIVE
Category: Meta

- **Team website**: the single HTML file that introduces one lab group.
- **Member card**: the block that introduces one team member.
- **Hot take**: a short, provocative opinion of a team member about AI.
- **Theme**: the visual mode of the page, either day (light) or night (dark).
- **Accent**: the one highlight color used for emphasis.
- **Breakpoint**: the viewport width at which the layout switches between mobile and desktop.
- **Data URI**: a way to embed a file (for example an image) directly inside the HTML.
- **Reduced motion**: a user setting in the operating system asking websites to minimise animation.
