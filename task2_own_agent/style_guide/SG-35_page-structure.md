# SG-35: Page structure

Status: ACTIVE (version 2)
Category: Structure

A team website consists of these parts, in this order:

1. `<header>` with the group name, tagline and theme toggle
2. `<main>` containing:
   - `<section id="team">` – the team introduction and all member cards
   - `<section id="future-of-se">` – the team's shared view on AI and the future of software engineering,
     with the heading "The Future of Software Engineering"
3. `<footer>`, see the current footer document

The section ids are used for navigation links and MUST be exactly as given.
Additional sections (for example a "fun statistics" section) MAY be added between the two required sections.
