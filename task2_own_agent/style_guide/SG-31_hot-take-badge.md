# SG-31: Hot take badge

Status: ACTIVE
Category: Components

Since version 2 of this guide, every member card MUST show the member's hot take in a badge.

- The badge is an element with the class `hot-take` inside the member card.
- It uses the accent color as background and white text.
- The text starts with the fire emoji 🔥.
- The badge is placed at the bottom of the card.
- Maximum text length: 140 characters, see the hot take writing document.
