# SG-25: Grid layout for member cards

Status: ACTIVE
Category: Layout

Member cards are laid out with CSS grid.

- Recommended: `grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));`
- Gap between cards: `1.5rem`.
- On mobile the cards are shown in one column, see the responsive breakpoints document.
- The main content SHOULD have a maximum width of `70rem` and be centered.
